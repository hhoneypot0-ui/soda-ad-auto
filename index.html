常见问题

攒到的天数在哪看？

手机：汽水音乐 App →「我的」→ 免费听/会员天数。电脑：双击「面板」，大数字 + 进度条一目了然（上限 30 天）。

需要 root / 会封手机吗？

不需要 root，只要一根数据线 + 开发者选项里的 USB 调试。工具只做真机界面点击；但自动化行为属于平台协议灰色地带，建议用不重要的账号，出现平台验证或领取明显变慢请立即停用。

支持 Mac / Linux 吗？

核心脚本跨平台（Python），桌面一键启动器目前为 Windows 设计；Linux/macOS 用户可直接命令行运行 python qishui_auto.py。

App 改版后点不动了？

不用改代码：打开 config.json，把新按钮的文字加进 reward_targets 等关键词列表即可。面板卡壳时自动存的 debug_clicks 截图会告诉你它看到了什么。
